OFFICE SETUP GUIDEF.A.E. COMMAND CENTER · FIRST-DAY INSTALL
← HOME
Everything to get the Command Center running in the office, in order. Steps 1 to 6 are the whole job — about 45 minutes. Steps 7 onward are the extras you can do in the first week. Print this and tick as you go.

What you need: the office computer (Windows), the office Wi-Fi password, a printer, and one staff phone to test with.

1Copy the folder to the office computer

5 MINUTES · DO THIS FIRST
  1. Copy the whole fae-command-center folder onto the office computer.
  2. Put it somewhere permanent — C:\FAE\fae-command-center or the Desktop. Not in Downloads, and not inside a synced OneDrive folder.
  3. Open the folder. You should see console.html, the two START-COMMAND-CENTER files, and folders called assets, data and logs.

Why not OneDrive: it syncs files while the software is writing them, which can corrupt a record halfway through a save. Keep the working folder local and use the backup step (10) to get copies off the machine.

2Install Python

10 MINUTES · ONE TIME ONLY

Python is what lets the office computer serve the pages to the staff phones. Without it the Command Center still works on that one computer, but no phone can reach it.

  1. Go to python.org/downloads and download the Windows installer.
  2. Run it. Tick "Add python.exe to PATH" on the very first screen — this is the step everyone misses, and nothing works without it.
  3. Click Install Now, then Close.

Check it worked: press Win+R, type cmd, press Enter, then type python --version. You should see a version number. If it says "not recognised", run the installer again and choose Modify → tick "Add to environment variables".

3Start it for the first time

2 MINUTES · YOU WILL DO THIS EVERY MORNING

Double-click START-COMMAND-CENTER-WIFI.bat.

Two things happen: a black window opens, and your browser opens the Console. The black window must stay open all day. Closing it stops the phones from being able to send anything. Minimise it, do not close it.

Read the black window — these five lines matter

F.A.E. COMMAND CENTER - office Wi-Fi mode ==================================================== On THIS computer : http://127.0.0.1:8765/console.html On a PHONE : http://192.168.1.10:8765/tasks.html <-- WRITE THIS DOWN Staff must be on the same Wi-Fi. Print the QR sheet from qr-poster.html so nobody has to type that address. OFFICE CODE for phones : 9881 <-- AND THIS Each phone types it once. Give it only to staff. To change it, edit data\staff-code.txt and restart. Visitors -> data\visitors In/out -> data\checkins Keep this window OPEN. Close it to stop. ----------------------------------------------------

Write down two things before you go further:

① the On a PHONE address (like 192.168.1.10:8765)
② the OFFICE CODE (4 digits)

If the phone address starts with anything other than 192.168. or 10. the window will say so in a warning. That usually means the computer is on a VPN. Turn the VPN off and restart the launcher — a phone cannot reach any other kind of address.

4Let the phones through the firewall

1 MINUTE · ONE TIME ONLY

The first time you start Wi-Fi mode, Windows asks "Allow access?"

  • Tick Private networks
  • Leave Public networks unticked
  • Click Allow access

Missed the box, or clicked Cancel? Right-click ALLOW-WIFI-FIREWALL.bat → Run as administrator. That adds the same rule.

This gate stops staff seeing figures they should not; it is not protection against someone who has the folder.

6Print the two QR sheets

10 MINUTES · THEN TAPE THEM UP

Console → Print & post → Staff QR Sheet. You print this page twice, changing the dropdown between prints.

Dropdown choiceWho it is forWhere it goes
Visitor Sign-In (door)Customers walking inAt the entrance, eye level
Daily Task TicketStaff, start and end of shiftInside the office, not public
  1. Check the address at the top matches the On a PHONE line you wrote down.
  2. Press TEST THE LINK. It should go green.
  3. Press PRINT THIS SHEET.
  4. Change the dropdown, print the second one.

If the address shows 127.0.0.1 or localhost, do not print. That address only works on the office computer itself, and the poster would be useless. The page turns red and tells you. Restart with the Wi-Fi launcher and reload the page.

Also print Terms & Waiver once and keep it in a folder at the desk, for anyone without a phone.

7Set up the door screen

5 MINUTES · OPTIONAL BUT WORTH IT

Any spare tablet or a second monitor at the desk. On it, open the phone address but ending in /checkin.html, for example http://192.168.1.10:8765/checkin.html.

  1. Sign in as Front desk (PIN only if you set one).
  2. Bookmark it, and set it as the browser home page.
  3. At the end of the day press 🔒 LOCK.

Why it locks: this screen lists every registered child by name with the adult responsible for them. It must not sit unlocked facing the public. Nothing shows until someone signs in.

8Test the whole loop

10 MINUTES · DO NOT SKIP THIS

Use one staff phone and walk the full circle before you trust it with real customers.

A · Staff ticket

  1. Connect the phone to the office Wi-Fi. Not mobile data.
  2. Scan the staff QR. The strip at the top should go green.
  3. Type the office code once when asked.
  4. Pick a name, tap TIME IN, tick a task, tap TIME OUT, SUBMIT.
  5. You should see "Received by the office computer."
  6. On the office PC: Dashboard → Daily Tickets. The ticket is there.
  7. Open data\tickets\. There is a .csv you can open in Excel.

B · Visitor sign-in

  1. Scan the visitor QR with any phone.
  2. Fill a name and mobile, press + Add another child, add a made-up child.
  3. The parent or guardian box appears — tick it, and the two required boxes.
  4. Register. Then on the door screen, search that name and tap the tile to check them IN.
  5. Dashboard → Visitors: they show as in the building, with the child under them.
  6. Delete the test family with Erase when you are done.

If all of that worked, you are live. Everything after this is optional.

9Google Sheet sync

20 MINUTES · OPTIONAL · DO IT IN WEEK ONE

Everything works without this. Add it when you want to read the numbers from home.

  1. Open the Google Sheet you want the data in.
  2. Extensions → Apps Script.
  3. Delete what is there. Paste the script from SYNC-SETUP.md (open that file in Notepad — the whole script is in it, ready to copy).
  4. Save. Then Deploy → New deployment → Web app. Execute as you, access Anyone with the link.
  5. Copy the deployment URL.
  6. Settings → Online Sync → paste it into the endpoint box, tick Auto-send when online, Save.
  7. Registry → any Export button → Send to Google Sheet. Check the sheet.

Tabs called MEMBERS, TASKS and PAYMENTS are created for you the first time. Sending twice does not duplicate rows. The visitor register is deliberately not sendable — children's details stay on the office computer.

10Backups — the habit that saves you

2 MINUTES A WEEK · THE MOST IMPORTANT HABIT HERE

All the records live in the browser on that one computer. A cleared cache, a Windows reinstall or a dead hard drive takes everything with it unless you have a backup.

  1. Console → Records & money → Registry Database.
  2. BACK UP EVERYTHING. Save it into data\backups\.
  3. Copy that file to a USB stick or Google Drive. Off the computer.

Do it every Friday and always before an update. To restore: Registry → Restore from file.

The backup contains everything, including children's names and health notes. Keep the USB stick locked up, or the Drive folder private. A backup in a drawer anyone can open is a data breach waiting to happen.
